# Підключення реєстрації та спільних посилань (Firebase)

Робиться **один раз** власником сайту. Відвідувачі нічого не вводять: вони просто реєструються e-mail і паролем, через Google або Apple.

Поки Firebase не підключено, редактор працює як раніше: проєкти зберігаються лише в браузері, а спільна робота можлива тільки через код запрошення.

Потрібні лише **Authentication** і **Cloud Firestore**. Обидва є в безкоштовному тарифі Spark. Firebase Storage і налаштування CORS не потрібні.

## 1. Створіть проєкт

1. Відкрийте <https://console.firebase.google.com> і натисніть **Add project**.
2. Дайте назву (наприклад, `vibsma`). Google Analytics можна вимкнути.

## 2. Увімкніть способи входу

**Build → Authentication → Get started → Sign-in method**:

- **Email/Password**: увімкнути (Enable).
- **Google**: увімкнути, вказати e-mail підтримки.
- **Apple**: необов'язково. Потрібен платний обліковий запис Apple Developer (Services ID). Без нього кнопка Apple покаже помилку «Цей спосіб входу ще не ввімкнено».

**Authentication → Settings → Authorized domains**: додайте адресу, де лежить сайт (наприклад, `vibsma.com` або `localhost`).

## 3. Створіть базу даних

1. **Build → Firestore Database → Create database**: режим **Production**, регіон `eur3` (Європа).
2. Вкладка **Rules**: вставте вміст файлу `firestore.rules` з цієї папки і натисніть **Publish**.

## 4. Скопіюйте налаштування в `js/config.js`

1. **Project settings** (шестерня) → **Your apps** → значок `</>` (Web).
2. Зареєструйте застосунок і скопіюйте `firebaseConfig`.
3. Відкрийте `js/config.js` і вставте значення:

```js
window.VIBSMA_CONFIG = {
  firebase: {
    apiKey: 'AIza…',
    authDomain: 'vibsma.firebaseapp.com',
    projectId: 'vibsma',
    appId: '1:…:web:…',
    messagingSenderId: '…'
  },
  siteUrl: 'https://vibsma.com'   // публічна адреса сайту — для посилань «Поділитися»
};
```

`apiKey` не є секретом: доступ до даних захищають правила з `firestore.rules`.

## 5. Розмістіть сайт в інтернеті

Вхід через Google і Apple та посилання для інших людей працюють тільки з адреси `https://…`. Сторінка `file://` для цього не підходить. Підійде будь-який статичний хостинг: Firebase Hosting, GitHub Pages, Netlify, Vercel.

Через Firebase Hosting це виглядає так:

```
npm install -g firebase-tools
firebase login
firebase init hosting   # public directory: .   single-page app: No
firebase deploy
```

## Що відбувається далі

- **Реєстрація e-mail:** після реєстрації на пошту приходить лист підтвердження. Пароль можна відновити через «Забули пароль?».
- **Збереження прогресу:** кожен проєкт (з фото, відео й звуком) і збережені стилі копіюються в обліковий запис після збереження. Після входу на іншому комп'ютері вони з'являються в «Проєктах».
- **Поділитися:** кнопка «Поділитися» (або «Спільна робота» → «Поділитися посиланням…») створює посилання. Хто його відкриє й увійде, редагує проєкт разом з вами в реальному часі: видно курсори й виділення інших. «Закрити доступ за посиланням» вимикає посилання.

## Ліміти безкоштовного тарифу

- 1 ГБ даних у Firestore.
- 50 000 читань і 20 000 записів на день.

Для невеликої команди цього досить. Великі відео швидко займають місце, тож для них краще перейти на тариф Blaze (оплата за використання).
